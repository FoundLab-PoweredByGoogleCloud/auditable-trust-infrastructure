# ATI Cookbooks
> **"Theory in Practice."**

This directory contains real-world scenarios and attacks to demonstrate how the ATI execution layer — the **F2F-RAaT** framework — responds to specific threats.

## 🥘 Recipes

| Cookbook | Scenario | Key Concepts |
| :--- | :--- | :--- |
| **[Pix HFT Attack](01_pix_hft_attack.md)** | **Financial Fraud**. A high-frequency transaction attack designed to bypass velocity limits. | `Velocity Vector`, `Sigmoid P(x)`, `BLOCK Decision` |
| **[Merchant Trust Growth](02_merchant_gradual_trust.md)** | **Reputation Building**. How a new merchant builds trust over time to increase limits. | `Time (T²)`, `Consistency`, `Allow Zones` |

## 📝 Note on Inputs
These cookbooks use simplified JSON representations of Facts. For the normative schemas of these facts, please refer to the **[Fact Schemas](../interface-contracts/FACT_SCHEMAS/)**.
